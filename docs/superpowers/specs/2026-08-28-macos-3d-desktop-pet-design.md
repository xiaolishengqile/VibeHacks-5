# 苹果电脑三维桌宠设计方案

## 目标

根据用户提供的绿色绒毛球形象，制作一个仅运行于当前苹果芯片电脑的实时三维桌宠。第一版必须能直接运行并看到效果，具备透明桌面窗口、始终置顶、拖拽、呼吸、眨眼和视线跟随能力。

## 范围

第一版包含：

- 绿色绒毛球形身体与两只玻璃质感绿色眼睛。
- 透明、无边框、始终置顶的桌面窗口。
- 鼠标拖拽移动桌宠，透明区域不阻挡下方应用。
- 呼吸、眨眼、轻微弹跳和视线跟随动画。
- 右键退出，避免无边框窗口无法关闭。
- 当前苹果芯片电脑上的运行脚本和应用导出配置。

第一版不包含语音、聊天、联网、开机启动、系统托盘、多角色和跨平台支持。这些能力不影响首个可见版本，后续按需增加。

## 技术选择

采用 Godot 4 稳定版作为桌面窗口、三维渲染和交互运行时，使用 GDScript 编写逻辑。首版模型完全在引擎内程序化生成，不依赖 Blender，目的是缩短从空项目到可见效果的路径。

选择该方案的原因：Godot 同时原生支持三维场景、材质渲染、透明窗口、窗口置顶和鼠标穿透区域，无需组合桌面容器、网页渲染器和系统插件。

## 视觉实现

### 身体

身体使用压扁的球体网格。基础层提供不透明绿色底色，外部默认叠加 16 层逐渐扩张的毛发壳层。毛发材质通过程序噪声裁剪像素，使轮廓呈现蓬松绒毛；壳层随时间产生轻微摆动。

默认使用中等毛发层数，并保留一个集中配置项。若运行时显卡占用偏高，可减少层数或将刷新率降为每秒 30 帧，而不改动模型与行为逻辑。

### 眼睛

每只眼睛由眼球、绿色虹膜、黑色瞳孔、透明角膜和两个高光点组成。瞳孔组根据屏幕鼠标相对桌宠窗口的位置做有限范围偏移，形成视线跟随效果。

### 阴影

透明窗口无法获得真实桌面接触阴影，因此使用带径向透明渐变的扁椭圆作为假阴影。阴影随弹跳幅度改变大小和透明度。

## 模块划分

- 主场景：只负责装配摄像机、灯光、桌宠和阴影。
- 桌宠外观：创建身体毛发层、眼睛和材质，不处理窗口行为。
- 动画控制：负责呼吸、眨眼、弹跳和视线跟随。
- 交互控制：负责点击、拖拽和右键退出。
- 桌面窗口：负责透明、无边框、置顶、初始位置和鼠标穿透区域。
- 集中配置：保存窗口大小、毛发层数、颜色、帧率和动画速度。

各模块通过明确的方法和信号协作，避免把渲染、行为与系统窗口代码写进同一个大文件。

## 运行流程

1. 应用启动并创建 480 × 420 像素的透明窗口。
2. 窗口移动到主屏幕右下方并保持置顶。
3. 主场景生成桌宠模型和毛发材质。
4. 动画控制器进入待机状态，循环呼吸和随机眨眼。
5. 鼠标移动时更新视线；左键拖动窗口；右键退出应用。

## 异常处理

- 毛发材质创建失败时，保留基础绿色身体，确保角色仍可见。
- 透明窗口不受系统支持时记录清晰错误，而不是显示全黑窗口。
- 鼠标穿透区域只覆盖透明背景，角色主体始终保持可交互。
- 应用退出时不保存临时动画状态，不产生额外数据文件。

## 验证标准

- 项目可由命令行无错误加载，所有脚本通过解析。
- 应用能在当前苹果芯片电脑启动并保持运行。
- 桌面上能看到无矩形背景的绿色三维绒毛球和两只眼睛。
- 桌宠显示在其他普通窗口上方。
- 呼吸、随机眨眼、视线跟随和拖拽均可观察到。
- 透明区域允许鼠标操作下方窗口，右键可退出桌宠。
- 运行日志无持续报错，并取得实际运行截图进行视觉检查。
